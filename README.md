# BIL24 · Java test assignments

Решение двух [публичных тестовых заданий BIL24](https://bil24.pro/vac_java_dev.html): оптимизация парсера мест и подстановка значений в неизменяемые текстовые шаблоны.

**Текущий этап: спецификация и планы переданы на ревью.** Реализация и измерения ещё не выполнены. Числа производительности появятся вместе с исходными результатами JMH и описанием окружения.

## Документы для ревью

1. [Спецификация: контракты, архитектура, тесты и критерии готовности](docs/superpowers/specs/2026-09-15-bil24-java-design.md).
2. [План 1: парсер, сравнение с оригиналом и измерения](docs/superpowers/plans/2026-09-15-seat-parser.md).
3. [План 2: шаблоны, тесты и измерения](docs/superpowers/plans/2026-09-15-template-renderer.md).
4. [Методика измерений до и после](docs/benchmark-methodology.md).

## Что будет в результате

- Парсер с сохранением API и наблюдаемого поведения оригинала.
- Сравнение с исходником BIL24 на фиксированных и сгенерированных данных, проверка параллельных вызовов.
- Небольшой рендерер шаблонов и объяснение алгоритма.
- JMH: время операции, пропускная способность и выделение памяти на операцию.
- Исходные JSON-результаты, окружение, команды воспроизведения и разбор ограничений.

## Предлагаемый стек

Java 17 как минимальная версия, проверка на JDK 17 и 21, основные измерения на JDK 21. Maven, JUnit 5.11.4 и JMH 1.37. Основной код использует только Java Standard Library; JUnit и JMH относятся к проверкам.

## Порядок работы

Спецификация и планы → ревью → реализация по Superpowers с тестами → измерения → финальное ревью кода.

Два задания имеют отдельные планы. Первый также создаёт общую сборку и средства измерений, которые использует второй. Репозиторий является самостоятельной работой кандидата и не представляет BIL24.
