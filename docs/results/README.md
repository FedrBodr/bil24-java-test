# Результаты измерений

Измерено на Apple M3 Max / macOS 14.4 / Corretto 21.0.6. Это синтетические microbenchmarks, а не нагрузочный тест сервера BIL24.

[Методика](../benchmark-methodology.md) · [окружение и точные команды](final/environment.md) · [первоначальный эталон до оптимизации](baseline-initial/environment.md).

В таблицах указаны среднее ± scoreError JMH (интервал 99,9%). Отношение сравнивает только пару с одинаковыми параметрами из одного итогового запуска. Выделение памяти B/op не равно объёму живых объектов или памяти процесса.

Парсер, измеренный код: [`79372b1`](https://github.com/FedrBodr/bil24-java-test/commit/79372b10bfd370b35b428fd6188a9748ad75523c).

## Интерпретация и ограничения

- Парсер сравнивается с оригиналом BIL24, в котором изменено только объявление пакета. Результаты первоначального запуска сохранены отдельно; итоговые отношения вычислены только из парного итогового запуска.
- Для шаблонов контрольный вариант — наша реализация с `compile` на каждом запросе. BIL24 не предоставил код рендерера. Измерение показывает эффект переноса подготовки за пределы запроса.
- Время содержит создание итоговой строки. Файловое I/O, сеть и генерация таблиц подстановки исключены из обеих веток.
- Корпуса фиксированы и синтетические. Производственные данные и распределение запросов BIL24 неизвестны.
- Общий выигрыш парсера нельзя точно разложить на вклад кэширования Pattern и однопроходной замены без дополнительных вариантов benchmark.
- Исходное регулярное выражение сохранено. Работа на произвольно длинных некорректных строках не получила гарантии линейного времени.
- Измерения выполнены на общем рабочем компьютере. Собственные сборки и тесты были остановлены на время JMH; фоновые процессы ОС и других приложений не контролировались.
- Между forks возможен разброс. Пересечение интервалов не доказывает ускорение. Среднее время операции не является p95/p99 задержки HTTP-запроса.
- Четырёхпоточный throughput — суммарный. Нет единого усреднённого коэффициента по разным сценариям.

Во всех 15 итоговых парах парсера интервалы разделены в пользу новой реализации. Регрессий среднего времени или throughput более 5% не обнаружено.
